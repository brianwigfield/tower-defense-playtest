Tower Defense desktop playtests

Play in your browser · Latest release and build revision

These are unsigned development builds, not production or Steam releases. Native builds use Forward+ rendering; a supported modern GPU and driver are required. Download only from this project's release page.

  • Windows x86_64 ZIP: extract the entire ZIP and run TowerDefense/TowerDefense.exe. Keep the executable and PCK together. SmartScreen may warn about the unknown publisher; proceed only if you trust the download.
  • macOS universal ZIP (Intel and Apple Silicon): extract and move TowerDefense/TowerDefense.app to Applications. This app is ad-hoc signed for execution, but not Developer ID signed or notarized. After attempting to open it, use System Settings > Privacy & Security > Open Anyway if you trust it. Do not disable Gatekeeper globally.
  • Linux x86_64 tar.gz: extract using tar -xzf, then run ./TowerDefense/TowerDefense.x86_64. If your extractor dropped executable permissions, use chmod +x on that executable. Keep the PCK alongside it.

Verify your download

Compare your archive's SHA-256 hash with SHA256SUMS: Get-FileHash in Windows PowerShell, shasum -a 256 on macOS, or sha256sum on Linux.

Downloads become available after the first successful native build of main is published. Browser and native builds publish independently; compare their build revisions when reporting a problem. Desktop campaign saves are separate from browser site data. Release artifacts contain game content that can be inspected; this repository does not contain the private development source history.
